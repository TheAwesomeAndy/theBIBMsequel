# CLAUDE.md: journal extension of the BIBM 2026 paper

Repository: `theBIBMsequel`. Extends Lane, Tang, Nelson, "On the Edge of Stability: Spiking
Reservoir State-Space Encoding of Affective EEG" (IEEE BIBM 2026 Doctoral Forum, S60204,
accepted) into a journal paper. Target: IEEE TNSRE (backup JBHI). Plan: `docs/ROADMAP.md`.

## Rules carried over from the BIBM repository (author's standing instructions)

- Phase-gated work. Finish the approved phase, report exact outputs, and stop for explicit
  approval before the next phase. State verification criteria before modifying files.
- Evidence over narrative. Report exact numbers, failures and limitations. No inflated
  claims, no invented state-of-the-art comparisons.
- Do not add AI-tool attribution, assistant footers, session links, or "generated by"
  language in commits, PR bodies, manuscripts, cover letters, or comments.
- Author wording rules for the manuscript (BIBM memory #16): banned in title and prose:
  observable, characterization/characterize, audit, behavior, response, metric;
  "robustness" banned in the title. No em dashes in manuscript prose.
- Clinical labels are task variables only. No diagnostic or biomarker claims. No hardware
  energy or latency claims.

## Data and privacy

- SHAPE is restricted. Raw EEG and any subject-level derivative never enter the repository.
  Scripts read data from `$SHAPE_DIR` / `$SHAPE_PICKLE` and write aggregate JSON only to
  `outputs/aggregate/`.
- Files ending `_SYNTHETIC.json` come from the synthetic test cohort and are git-ignored.

## Code

- `sequel/` is the only implementation. `bibm_baseline/` is a frozen copy of the
  camera-ready (source commit 1667277) and must not be edited.
- Run `python -m pytest -q tests` before every commit.
- Any change to the reservoir, features or protocol must keep
  `experiments/check_bibm_regression.py` passing on the BIBM pickle.
